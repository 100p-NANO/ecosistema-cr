# Guía de RocaKids

## Antes del domingo
- Para servir con niños hacen falta **antecedentes vigentes**. Si no están al día, el sistema no deja asignar el rol. La lista de lo que falta está en la ficha de antecedentes de cada servidor.
- En el equipo de la sala: **«Preparar sin conexión»**. Guarda las salas, los niños y sus acudientes en el equipo, para trabajar aunque se caiga el internet.

## Recibir a un niño
1. Elija la sala y busque al niño.
2. Elija **quién lo entrega**: solo aparecen sus acudientes registrados.
3. El sistema da un **código de entrega**. Es el único con el que se devuelve al niño.

## Entregar
Pida el código y elija quién lo recoge. El sistema pregunta a la base los acudientes **autorizados para retirar** en ese momento (si no hay conexión, usa lo guardado en el equipo). Si nadie autorizado está registrado, **no se entrega**: se llama a la dirección de RocaKids.

## Lo que nunca se hace
Entregar a alguien que no está autorizado, anotar el código en papel a la vista, o exportar datos de los niños (el sistema no lo permite).
